接入前准备

  • 宿主客户端完成用户登录并获得 liveUserId、imUserId、liveToken。
  • 宿主动态传入 sceneType：1 直播间，2 IM 群。
  • 宿主动态传入 sceneId，SDK 不内置固定场景。
  • 正式环境必须使用 HTTPS/WSS，无需配置 ATS 例外。

5 分钟快速接入

  1. 通过 SPM 或 CocoaPods 添加 CocosGameSDK 0.6.18。
  2. 主窗口创建后调用 initializeWithWindow:launchOptions:initialize(window:launchOptions:)。
  3. 客户端登录后创建 CocosGameSessionConfig。
  4. 提供游戏容器视图，调用 openGame:sessionConfig:inContainer:fromViewController:openGame(_:sessionConfig:container:viewController:)。
  5. 离开页面时调用 closeclose()。
#import <CocosGameSDK/CocosGameSDK.h>

[[CocosGameSDK shared] initializeWithWindow:self.window launchOptions:launchOptions];

[CocosGameSDK shared].delegate = self;
[[CocosGameSDK shared] openGame:@"niuniu"
                  sessionConfig:sessionConfig
                    inContainer:self.gameContainer
             fromViewController:self];
import CocosGameSDK

CocosGameSDK.shared.initialize(window: window, launchOptions: launchOptions)

CocosGameSDK.shared.delegate = self
CocosGameSDK.shared.openGame("niuniu",
                             sessionConfig: sessionConfig,
                             container: gameContainer,
                             viewController: self)

SDK 不提供生产登录。UID、Token、Scene Type、Scene ID 必须由宿主客户端传入。

初始化 SDK

在宿主主窗口创建后初始化一次。

使用 AppDelegate 窗口的宿主在 application:didFinishLaunchingWithOptions: 中调用；使用 SceneDelegate 的宿主在 scene:willConnectToSession:options: 中创建窗口后调用，launchOptions 传 nil。

按宿主工程类型三选一：AppDelegate 窗口、SceneDelegate（Xcode UIKit 模板默认）、SwiftUI（见下方「SwiftUI 接入」）。SceneDelegate 与 SwiftUI 中 launchOptions 传 nil。

SceneDelegate

func scene(_ scene: UIScene, willConnectTo session: UISceneSession,
           options connectionOptions: UIScene.ConnectionOptions) {
    guard let windowScene = scene as? UIWindowScene else { return }
    let window = UIWindow(windowScene: windowScene)
    window.rootViewController = rootViewController
    CocosGameSDK.shared.initialize(window: window, launchOptions: nil)
    window.makeKeyAndVisible()
    self.window = window
}

AppDelegate

AppDelegate

- (BOOL)application:(UIApplication *)application
    didFinishLaunchingWithOptions:(NSDictionary *)launchOptions {
    self.window = [[UIWindow alloc] initWithFrame:UIScreen.mainScreen.bounds];
    self.window.rootViewController = rootViewController;
    [[CocosGameSDK shared] initializeWithWindow:self.window launchOptions:launchOptions];
    [self.window makeKeyAndVisible];
    return YES;
}

// 可选：窗口方向跟随 SDK（全屏不旋转设备，始终返回竖屏）

    return CocosGameSDK.shared.preferredOrientationMask;
}

    window.rootViewController = rootViewController
    CocosGameSDK.shared.initialize(window: window, launchOptions: launchOptions)
    window.makeKeyAndVisible()
    self.window = window
    return true
}

// 可选：窗口方向跟随 SDK（全屏不旋转设备，始终返回竖屏）

                 supportedInterfaceOrientationsFor window: UIWindow?) -> UIInterfaceOrientationMask {

}

创建会话

NSError *error = nil;
CocosGameSessionConfig *sessionConfig = [[CocosGameSessionConfig alloc]
    initWithWebsocketURL:websocketURL
              apiBaseURL:apiBaseURL
              liveUserId:liveUserId
                imUserId:imUserId
               liveToken:liveToken
               sceneType:CocosGameSceneTypeIMGroup
                 sceneId:sceneId
                 tableId:0
           clientVersion:appVersion
              deviceType:@"iOS"
                   error:&error];
if (!sessionConfig) {
    NSLog(@"游戏会话参数不合法：%@", error.localizedDescription);
    return;
}
let sessionConfig: CocosGameSessionConfig
do {
    sessionConfig = try CocosGameSessionConfig(websocketURL: websocketURL,
                                               apiBaseURL: apiBaseURL,
                                               liveUserId: liveUserId,
                                               imUserId: imUserId,
                                               liveToken: liveToken,
                                               sceneType: .imGroup,
                                               sceneId: sceneId,
                                               tableId: 0,
                                               clientVersion: appVersion,
                                               deviceType: "iOS")
} catch {
    print("游戏会话参数不合法：\(error.localizedDescription)")
    return

客户端与 SDK 职责

客户端负责

  • 账号登录、Token 刷新和退出。
  • UID、Token、Scene Type、Scene ID。
  • 提供游戏容器视图与页面导航。
  • 退出确认框、返回离开处理。
  • 会话失效后返回登录流程。
  • 自定义钱包、充值或其他业务页面。

SDK 负责

  • 游戏引擎挂载与内置资源加载。
  • 大厅 HTTP、WebSocket、重连和快照恢复。
  • 游戏音频和生命周期。
  • 入座、下注、结算与界面状态。
  • 内嵌与全屏切换、等比适配。
  • 记录与规则、下注卡片与通用事件桥。

全屏、弹窗与生命周期

  • 全屏时 SDK 将游戏视图旋转 90° 铺满屏幕，宿主页面保持竖屏，无需在 Info.plist 中开启横屏。
  • 不要修改游戏容器的 transform，也不要在全屏期间改动容器约束。
  • 竖屏内嵌时，未接管的「记录与规则」以 SDK 底部弹窗展示，下注阶段在游戏容器下方展示 SDK 加注筹码卡片（覆盖在宿主内容上，下注或倒计时结束后自动收起）；宿主可接管自绘，见「竖屏宿主自绘」。全屏时下注、记录与退出确认都在牌桌内展示。
  • 进入后台时 SDK 暂停音频和实时连接；回前台重新认证并拉取权威桌态后恢复交互。
  • 游戏展示期间 SDK 使用 Playback 音频会话（与其他音频混音），关闭游戏后恢复。
  • App 被强杀时，座位释放依赖服务端断线自动离座。

我的记录

「我的记录」由 SDK 内置实现，客户端无需调用任何 API、无需注册回调。用户在游戏内点击「规则」按钮，切换到「我的记录」页签即可查看本人注单。

  • SDK 使用 CocosGameSessionConfig 中的 apiBaseURL、liveUserId、liveToken 请求后台，与入座、下注接口相同。
  • 当前本桌：POST /api/lobby/bet/table/mine；历史场次：POST /api/lobby/bet/history。
  • 每页 20 条，滑到底部自动加载下一页；失败显示点击重试，无数据显示空状态。

迷你条

宿主可把牌桌缩成 362:50 的横条，下方宿主内容随之上移。容器尺寸由宿主控制：先切换容器约束，再调用 SDK；SDK 同步渲染尺寸后通知牌桌切换为迷你条。

预加载（进群秒开，0.6.8）

打开游戏要启动引擎、加载资源并连接牌桌，约 1～3 秒。把打开时机提前到「进入群 / 直播间」，用户点游戏入口时牌桌已在后台就绪，展开即显示。

竖屏下注弹窗：三种接入方式

竖屏内嵌时，每局下注阶段要给玩家展示「下注对象 + 筹码」的下注界面。宿主可以直接使用游戏（SDK）提供的加注卡片，也可以完全自己画；使用 SDK 卡片时，还可以把它放进宿主自己的容器里决定位置。三种方式任选其一，不需要的不用接。全屏横屏时统一由游戏内弹窗展示，与这里的选择无关。

方式宿主要做的界面下注提交适合
A. SDK 默认位置什么都不用做SDK 加注卡片，紧贴游戏容器下方（左右各 14pt），覆盖在宿主内容之上SDK 处理快速接入、没有特殊布局要求
B. 放入宿主容器（0.6.12）提供一个 UIView 容器，调用 setBetPanelContainer:setBetPanelContainer(_:)SDK 加注卡片，位置与宽度由宿主容器决定SDK 处理想用游戏提供的界面，但要放在页面指定位置（如聊天输入框上方）
C. 宿主自绘实现下注代理回调，自己画界面并提交完全由宿主决定（UIKit / SwiftUI 均可）宿主调用 submitBetWithRoundId:…submitBet(…)要与 App 视觉完全一致，或需要埋点、二次确认等自定义交互
  • 优先级：delegate 实现了 gameSDKDidReceiveBetOptions:gameId:gameSDKDidReceiveBetOptions(_:gameId:)（方式 C）时，方式 A / B 都不生效；未实现时，设置了容器走方式 B，否则走方式 A。
  • 方式 C 由是否实现该回调决定；如需运行时切换，可更换 delegate 对象。setBetPanelContainer:nilsetBetPanelContainer(nil) 回到默认位置。
  • 所有接口都须在主线程调用，回调也都在主线程。

方式 A：SDK 默认位置

不实现下注回调、不设置容器即可。下注阶段 SDK 卡片自动出现在游戏容器下方，玩家点筹码即提交，下注成功或截止后自动收起。卡片会盖住游戏下方的宿主内容，如需避让请改用方式 B。

  • 下注阶段：卡片四边贴齐容器，容器高度随卡片内容撑开。
  • 点筹码提交、下注截止或离局：卡片高度归零并隐藏，容器高度回到 0，相邻的宿主内容自动回位（使用 Auto Layout 时无需额外处理）。
  • 切到全屏横屏时卡片收起，由游戏内弹窗接管。

  • 已入座闲家：只有本座一个注区，卡片只显示「请加注筹码」与筹码按钮。

常见问题

  • 设置了容器但卡片仍在默认位置？ 检查 delegate 是否实现了下注回调（方式 C 优先），以及是否在主线程调用、容器是否已加入视图层级。

常见问题

打开后黑屏

确认已调用 initializeWithWindow:launchOptions:initialize(window:launchOptions:)，容器视图在 openGame 前已完成布局且尺寸不为 0。模拟器首次启动较慢，等待 30 秒左右。

模拟器提示架构不匹配

0.6.0 起模拟器切片同时包含 arm64 与 x86_64。如果仍提示架构不匹配，确认已升级到 0.6.0，并删除 Build Settings 中旧版本要求的 EXCLUDED_ARCHS[sdk=iphonesimulator*] = arm64；0.6.0 之前的版本只有 x86_64，需在 Rosetta 模拟器运行。

启动崩溃提示找不到 CocosGameSDK.framework

本地集成时确认设置为 Embed & Sign，而不是 Do Not Embed。

WebSocket 一直认证失败

确认 liveUserId 与 liveToken 匹配、未过期，HTTP 与 WebSocket 属于同一环境。

大厅没有可用桌

确认 Scene Type、Scene ID 与后台开桌场景一致，指定的 tableId 仍有效。
