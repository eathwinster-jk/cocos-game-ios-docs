v0.1.9 首个 iOS 版本：功能与 Android SDK 0.1.9 对齐，牛牛牌桌在宿主页面容器内嵌展示，支持全屏切换；竖屏下「记录与规则」底部弹窗与加注筹码卡片为原生实现，样式与 Android 一致；游戏展示期间静音键开启也能正常播放声音。

接入前准备

  • 宿主客户端完成用户登录并获得 liveUserId、imUserId、liveToken。
  • 宿主动态传入 sceneType：1 直播间，2 IM 群。
  • 宿主动态传入 sceneId，SDK 不内置固定场景。
  • 正式环境必须使用 HTTPS/WSS，无需配置 ATS 例外。

5 分钟快速接入

  1. 通过 SPM 或 CocoaPods 添加 CocosGameSDK 0.1.9。
  2. 主窗口创建后调用 initializeWithWindow:launchOptions:。
  3. 客户端登录后创建 CocosGameSessionConfig。
  4. 提供游戏容器视图，调用 openGame:sessionConfig:inContainer:fromViewController:。
  5. 离开页面时调用 close。
#import <CocosGameSDK/CocosGameSDK.h>

[[CocosGameSDK shared] initializeWithWindow:self.window launchOptions:launchOptions];

[CocosGameSDK shared].delegate = self;
[[CocosGameSDK shared] openGame:@"niuniu"
                  sessionConfig:sessionConfig
                    inContainer:self.gameContainer
             fromViewController:self];

SDK 不提供生产登录。UID、Token、Scene Type、Scene ID 必须由宿主客户端传入。

初始化 SDK

在宿主主窗口创建后初始化一次。使用 SceneDelegate 的宿主在 scene:willConnectToSession:options: 中创建窗口后调用，launchOptions 传 nil。

- (BOOL)application:(UIApplication *)application
    didFinishLaunchingWithOptions:(NSDictionary *)launchOptions {
    self.window = [[UIWindow alloc] initWithFrame:UIScreen.mainScreen.bounds];
    self.window.rootViewController = rootViewController;
    [[CocosGameSDK shared] initializeWithWindow:self.window launchOptions:launchOptions];
    [self.window makeKeyAndVisible];
    return YES;
}

// 可选：窗口方向跟随 SDK（全屏不旋转设备，始终返回竖屏）
- (UIInterfaceOrientationMask)application:(UIApplication *)application
    supportedInterfaceOrientationsForWindow:(UIWindow *)window {
    return CocosGameSDK.shared.preferredOrientationMask;
}

SDK 自动监听前后台、终止和内存警告，宿主无需转发 AppDelegate 生命周期。

创建会话并打开游戏

创建会话

NSError *error = nil;
CocosGameSessionConfig *sessionConfig = [[CocosGameSessionConfig alloc]
    initWithWebsocketURL:websocketURL
              apiBaseURL:apiBaseURL
              liveUserId:liveUserId
                imUserId:imUserId
               liveToken:liveToken
               sceneType:CocosGameSceneTypeIMGroup
                 sceneId:sceneId
                 tableId:0
           clientVersion:appVersion
              deviceType:@"iOS"
                   error:&error];
if (!sessionConfig) {
    NSLog(@"游戏会话参数不合法：%@", error.localizedDescription);
    return;
}

打开与关闭

宿主提供一个已布局的容器视图（建议宽高比 375:211），页面显示后打开：

- (void)viewDidAppear:(BOOL)animated {
    [super viewDidAppear:animated];
    if (self.hasOpened) return;
    self.hasOpened = YES;
    CocosGameSDK.shared.delegate = self;
    [self.view layoutIfNeeded];
    [[CocosGameSDK shared] openGame:@"niuniu"
                      sessionConfig:self.sessionConfig
                        inContainer:self.gameContainer
                 fromViewController:self];
}

- (void)viewDidDisappear:(BOOL)animated {
    [super viewDidDisappear:animated];
    if (self.isMovingFromParentViewController) [[CocosGameSDK shared] close];
}

// 全屏期间隐藏状态栏
- (BOOL)prefersStatusBarHidden {
    return CocosGameSDK.shared.isFullscreen;
}

同一时间只能打开一个游戏；close 后可再次 openGame 并重新读取会话。

代理回调

宿主实现 CocosGameSDKDelegate，delegate 为弱引用。

回调必选说明
gameSDKDidChangeState:是SDK 状态变化
gameSDKDidFailWithError:是SDK 失败及上下文
gameSDKDidRequestExitWithCompletion:是游戏中请求离开座位，宿主弹确认框后回调 completion(YES/NO)
gameSDKDidChangePlayingState:是是否参与座位游戏
gameSDKDidRequestBack否牌桌返回箭头；实现后宿主自行 close 并关闭页面，未实现时 SDK 直接 close
gameSDKDidInvalidateSessionWithMessage:否Token 失效等，SDK 已关闭游戏，宿主应清理凭据并回登录页
gameSDKDidReceiveEvent:payloadJSON:gameId:否游戏发出的通用业务事件
gameSDKDidUpdateGame:… / gameSDKDidFailUpdateGame:…否模块更新进度与失败

退出确认示例

- (void)gameSDKDidRequestExitWithCompletion:(void (^)(BOOL))completion {
    UIAlertController *alert = [UIAlertController alertControllerWithTitle:@"退出游戏？"
        message:@"当前游戏正在进行中，离开后游戏将结束并结算。"
        preferredStyle:UIAlertControllerStyleAlert];
    [alert addAction:[UIAlertAction actionWithTitle:@"离开" style:UIAlertActionStyleDestructive
        handler:^(UIAlertAction *action) { completion(YES); }]];
    [alert addAction:[UIAlertAction actionWithTitle:@"取消" style:UIAlertActionStyleCancel
        handler:^(UIAlertAction *action) { completion(NO); }]];
    [self presentViewController:alert animated:YES completion:nil];
}

通用事件

接收游戏事件

- (void)gameSDKDidReceiveEvent:(NSString *)event
                   payloadJSON:(NSString *)payloadJSON
                        gameId:(NSString *)gameId {
    if ([event isEqualToString:@"niuniu.wallet.open"]) [self openWalletPage];
}

向游戏发送事件

[[CocosGameSDK shared] sendGameEvent:@"niuniu.wallet.closed"
                         payloadJSON:@"{\"isBalanceChanged\":true}"];
  • 事件名必须匹配 ^[a-z][a-z0-9_.-]{0,63}$，建议带模块前缀。
  • 载荷必须是 JSON 对象字符串或 nil。
  • Token、密码等敏感数据不得放入通用事件。

公共 API

API用途
initializeWithWindow:launchOptions:使用宿主窗口初始化 SDK
configure:传入 CocosGameSDKConfig 配置模块更新；不使用远程更新时无需调用
openGame:sessionConfig:inContainer:fromViewController:使用宿主会话在容器内打开游戏
close关闭游戏并释放连接与座位
toggleFullscreen宿主主动切换内嵌 / 全屏
pause / resume暂停、恢复游戏
setMuted:设置静音
sendGameEvent:payloadJSON:向游戏发送通用事件
state / isFullscreen / gameId / preferredOrientationMask只读状态

CocosGameSessionConfig 参数

参数规则
websocketURL必须为 wss://
apiBaseURL必须为 https://
liveUserId客户端登录后的直播 UID（登录响应 uid），用于大厅鉴权，大于 0
imUserId客户端登录后的 IM UID（登录响应 userinfo.imUserId），用于识别本人座位，大于 0
liveToken客户端登录后的有效 Token
sceneTypeCocosGameSceneTypeLiveRoom（1 直播间）或 CocosGameSceneTypeIMGroup（2 IM 群）
sceneId客户端当前场景 ID，按字符串原样传入，不允许为空
tableId0 自动选择，正整数指定桌台
clientVersion宿主客户端版本
deviceTypeiOS

参数不合法时初始化返回 nil，error 中给出原因，不应继续打开游戏。

客户端与 SDK 职责

客户端负责

  • 账号登录、Token 刷新和退出。
  • UID、Token、Scene Type、Scene ID。
  • 提供游戏容器视图与页面导航。
  • 退出确认框、返回离开处理。
  • 会话失效后返回登录流程。
  • 自定义钱包、充值或其他业务页面。

SDK 负责

  • 游戏引擎挂载与内置资源加载。
  • 大厅 HTTP、WebSocket、重连和快照恢复。
  • 游戏音频和生命周期。
  • 入座、下注、结算与界面状态。
  • 内嵌与全屏切换、等比适配。
  • 记录与规则、下注卡片与通用事件桥。

全屏、弹窗与生命周期

  • 全屏时 SDK 将游戏视图旋转 90° 铺满屏幕，宿主页面保持竖屏，无需在 Info.plist 中开启横屏。
  • 不要修改游戏容器的 transform，也不要在全屏期间改动容器约束。
  • 竖屏内嵌时「记录与规则」以底部弹窗展示，下注阶段在游戏容器下方展示加注筹码卡片（覆盖在宿主内容上，下注或倒计时结束后自动收起）；全屏时弹窗在牌桌内展示。
  • 进入后台时 SDK 暂停音频和实时连接；回前台重新认证并拉取权威桌态后恢复交互。
  • 游戏展示期间 SDK 使用 Playback 音频会话（与其他音频混音），关闭游戏后恢复。
  • App 被强杀时，座位释放依赖服务端断线自动离座。

我的记录

「我的记录」由 SDK 内置实现，客户端无需调用任何 API、无需注册回调。用户在游戏内点击「规则」按钮，切换到「我的记录」页签即可查看本人注单。

  • SDK 使用 CocosGameSessionConfig 中的 apiBaseURL、liveUserId、liveToken 请求后台，与入座、下注接口相同。
  • 当前本桌：POST /api/lobby/bet/table/mine；历史场次：POST /api/lobby/bet/history。
  • 每页 20 条，滑到底部自动加载下一页；失败显示点击重试，无数据显示空状态。

常见问题

打开后黑屏

确认已调用 initializeWithWindow:launchOptions:，容器视图在 openGame 前已完成布局且尺寸不为 0。Rosetta 模拟器首次启动较慢，等待 30 秒左右。

模拟器提示架构不匹配

当前模拟器切片只有 x86_64。在 Apple Silicon 上选择 Rosetta 模拟器，或在 Build Settings 中设置 EXCLUDED_ARCHS[sdk=iphonesimulator*] = arm64。

启动崩溃提示找不到 CocosGameSDK.framework

本地集成时确认设置为 Embed & Sign，而不是 Do Not Embed。

WebSocket 一直认证失败

确认 liveUserId 与 liveToken 匹配、未过期，HTTP 与 WebSocket 属于同一环境。

大厅没有可用桌

确认 Scene Type、Scene ID 与后台开桌场景一致，指定的 tableId 仍有效。

上线验收清单

  • SDK 只初始化一次，打开前已设置 delegate。
  • UID、Token、Scene Type、Scene ID 均来自客户端。
  • 能进入牛牛桌并收到实时阶段。
  • 入座、离座、下注和结算正常。
  • 记录与规则、下注卡片、退出确认关闭后按钮仍可点击。
  • 小屏、大屏往返后全部按钮仍可点击。
  • 返回箭头离开、再次进入游戏正常。
  • 进入后台再返回能够恢复桌态。
  • Token 失效后能返回客户端登录流程。
  • iOS 16 与当前主流系统真机至少各完成一次冒烟测试。
  • 未记录 Token、密码或完整敏感响应。
